# Marginalia Reader

A private e-book and PDF reader that installs on your phone as an app (PWA).

- Reads PDF, EPUB, TXT, Markdown, HTML, FB2 and CBZ.
- Highlights, notes, bookmarks, collections, search, reading statistics and goals.
- Read aloud with your device's voices: word highlighting, speed, voice choice, sleep timer.
- Books and notes are stored only on your device (IndexedDB). Works offline once installed.

## Install on your phone
- **iPhone / iPad:** open the site in Safari → Share → Add to Home Screen.
- **Android:** open the site in Chrome → Install app (or menu → Add to Home screen).

Built with vanilla JavaScript and PDF.js. No build step: GitHub Pages serves the files as they are.
